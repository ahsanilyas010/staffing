# Assorted Staffing

Monorepo for Assorted Group's public staffing website and internal recruitment HRM.

## Structure

```
staffing/
├── index.html         # Public website — staffing.assorted.group
├── logo.png
├── supabase-setup.sql  # Original candidates table setup
├── CONTEXT.md          # Full project context and architecture reference
└── hrm/                # Recruitment HRM dashboard — hrm.assorted.group
    ├── HIRING_MODULE_SPEC.md  # Full hiring automation spec (phases 1-6)
    └── SETUP.md               # Setup and deployment guide
```

See [`CONTEXT.md`](./CONTEXT.md) for the full architecture, data flow, and current project status.
See [`hrm/SETUP.md`](./hrm/SETUP.md) for setting up the HRM dashboard locally or in production.
